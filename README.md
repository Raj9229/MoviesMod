# 🎬 MoviesMod

A movie ticket booking web application built using **MERN stack** .

## 🚀 Tech Stack

### Frontend

* React
* Tailwind CSS
* Axios

### Backend

* Node.js
* Express.js
* MongoDB

## 📁 Project Structure

```text
Moviesmod/
├── frontend/
├── backend/
├── .gitignore
└── README.md
```

## ✨ Planned Features

* Browse movies
* View movie details
* User authentication
* Movie ticket booking
* Seat selection
* Booking history
* Admin panel
